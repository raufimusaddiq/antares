# Quickstart: validating the feature

Prerequisites: Go and Node toolchains as in AGENTS.md; `ONLY=<view> node scripts/browser-check.mjs` with a Chromium (`CHROME`, `PLAYWRIGHT_CORE`).

0. Create the GitHub issue for this spec before the design PR.
1. **Toolbar (US1)**: `ONLY=editor-toolbar` types a sentence, makes a word bold and a line a heading, then makes 50 cursor moves and selections (arrow keys, clicks, shift-selection, a partly bold range); after each, every button's `aria-pressed` equals the truth read from the DOM at the caret (SC-001). vitest `formatState.test.ts` covers on/off/mixed for marks and blocks.
2. **Progress (US2)**: Go test scripts the fake Hermes (`reasoning` -> `tool.started` x2 -> `tool.completed` -> deltas -> `run.completed`) and reads the check at each point: stage `reading`, `searching` with lookups 2, `writing`; `last_event_at` moves; a stalled script times out as `timed_out`. `ONLY=blog-editor` shows the steps, the clock, the stalled and stopped screens, and reloading mid-check shows the real step (FR-007).
3. **Editor (US3)**: Go tests: envelope v2 accepts good edits and drops a bad kind, a missing span, an invented figure, a URL; decisions are the author's only; a draft edit does not make a check out of date; a block whose place is gone is skipped at publish; limits are shared. vitest: cards, accept applies one undoable change, reject changes nothing, no longer applicable, language. Browser: open the panel, run a check on the mock, accept one, reject one, undo, no overlap at 320/390/820/1280.
4. **Production** (after deploy, synthetic accounts, cleanup): a finished rough draft and a bare framework of five headings, in Indonesian and in English; record in `validation.md`: suggestions per draft, no invented figures, language, progress steps seen, the draft unchanged until accepted, publish without accepting publishes the original (SC-004 to SC-007).
